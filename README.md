## About

**Begweb** is a beginner-friendly project designed to help developers learn how to build a **React webpage with authentication**.

The project combines:

* ⚛️ **React** — Frontend development
* 🎨 **Tailwind CSS** — Styling and UI design
* 🥟 **Bun** — Backend server and runtime
* 🍪 **Cookies** — Session management

The initial project structure was generated using:

```text
Bun INIT → React → Blank
```

It was then modified and expanded to focus on a simple **login and logout authentication flow**.

For learning purposes, the application uses a short **60-second session**. When a user logs in, their session is stored using a cookie and remains valid for 60 seconds before expiring.

> **Note:** This project is intended for learning and experimentation. The authentication implementation is intentionally simple and should not be considered production-ready.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/francis-ramos/begweb.git
cd begweb
```

### 2. Install dependencies

```bash
bun install
```

### 3. Start the development server

```bash
bun run dev
```

Once the server is running, open the URL provided in your terminal.

## Project Purpose

This project was created primarily as a **learning resource for beginners** who want to understand how a React frontend can communicate with a backend server and handle a basic authentication flow.

Rather than providing a complex authentication system, Begweb keeps the implementation small and easy to understand, making it easier to experiment with:

* HTTP requests
* Authentication
* Login/logout flows
* Cookies
* Sessions
* React components
* Tailwind CSS
* Bun's development environment
