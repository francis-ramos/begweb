This repository was made for beginners to help them develop a React webpage with authentication feature, the webpage uses TailwindCSS for design, and Bun for backend server. Additionally, the whole structure itself was a template from <code>Bun INIT -> React -> Blank</code>, however, with few modification by the developer, the project was now focused on login and logout feature that saves the user for 60 seconds and uses cookie as a way to save the session.
